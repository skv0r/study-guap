# Инструкция по использованию интерактивной карты

## Что добавлено

1. **Зависимости**:
   - Яндекс MapKit SDK (версия 4.4.0-full)
   - Обновлена версия базы данных Room до версии 3

2. **Файлы**:
   - `MapActivity.kt` - основная активность с картой
   - `activity_map.xml` - layout для карты
   - `MapMarker.kt` - модель данных для меток
   - `MapMarkerDao.kt` - DAO для работы с метками в БД
   - Обновлен `AppDatabase.kt` для поддержки меток
   - Обновлен `MainActivity.kt` - добавлен пункт меню "Карта"
   - Обновлен `bottom_menu.xml` - добавлена кнопка карты

3. **Разрешения**:
   - ACCESS_FINE_LOCATION
   - ACCESS_COARSE_LOCATION

## Функционал

### Основные возможности:

1. **Просмотр карты Москвы**:
   - Карта центрирована на Красной площади
   - Масштабирование жестами
   - Перемещение по карте

2. **Добавление меток**:
   - **Способ 1**: Нажать кнопку "Добавить метку" и выбрать из 10 известных мест Москвы:
     - Красная площадь
     - Кремль
     - Храм Василия Блаженного
     - ГУМ
     - Большой театр
     - МГУ
     - Останкинская башня
     - Парк Горького
     - ВДНХ
     - Третьяковская галерея
   
   - **Способ 2**: Долгое нажатие на любое место на карте - откроется диалог добавления метки

3. **Просмотр информации о метке**:
   - Нажмите на метку на карте
   - Откроется диалог с информацией:
     - Название
     - Описание
     - Координаты (широта/долгота)
   - Возможность удалить конкретную метку

4. **Удаление меток**:
   - Кнопка "Очистить метки" - удаляет все метки с карты
   - Или через диалог информации о метке

5. **Возврат к центру**:
   - Кнопка FAB (круглая кнопка) в правом нижнем углу - возвращает к центру Москвы

6. **Сохранение данных**:
   - Все метки сохраняются в локальной базе данных Room
   - При повторном открытии карты метки автоматически загружаются

## Как тестировать в Android Studio

1. **Откройте проект** в Android Studio

2. **Синхронизация Gradle**:
   - При первом открытии появится предложение синхронизировать проект
   - Нажмите "Sync Now"
   - Gradle скачает зависимость Яндекс MapKit (может занять время)

3. **Запуск приложения**:
   - Подключите Android устройство или запустите эмулятор
   - Нажмите Run (зеленая стрелка) или Shift+F10
   - Приложение скомпилируется и запустится

4. **Использование**:
   - В нижней навигационной панели появится новая иконка "Карта"
   - Нажмите на неё - откроется карта Москвы
   - Попробуйте добавить метку через кнопку "Добавить метку"
   - Попробуйте долгое нажатие на карте
   - Нажмите на метку для просмотра информации

## Возможные проблемы

### 1. Ошибка "API key not found"
**Решение**: API ключ уже прописан в коде:
- `AndroidManifest.xml` - в meta-data
- `MapActivity.kt` - в методе onCreate

### 2. Ошибка сборки из-за кириллицы в пути
**Решение**: Уже добавлено `android.overridePathCheck=true` в `gradle.properties`

### 3. Карта не отображается
**Решение**: 
- Проверьте интернет-соединение (карта загружается из сети)
- Убедитесь, что разрешения на геолокацию предоставлены

### 4. Метки не сохраняются
**Решение**: База данных была обновлена до версии 3. При первом запуске Room пересоздаст БД автоматически.
