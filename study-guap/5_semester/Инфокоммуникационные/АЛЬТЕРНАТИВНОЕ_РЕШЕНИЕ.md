# АЛЬТЕРНАТИВНОЕ РЕШЕНИЕ

## Проблема сохраняется

Результат все еще записывается в 006B вместо 006C.

## Новый подход: Используем ADDB2 вместо ADDB3

Может быть проблема в том, что ADDB3 работает не так, как ожидается. Попробуем использовать ADDB2 (2 операнда) + MOVB для записи результата.

### Вариант А: ADDB2 + MOVB

**Шаг 1: Программа**

```
Адрес 03C0: 80    (код операции ADDB2)
Адрес 03C1: 90    (@(R0)+ - первый операнд X1)
Адрес 03C2: 91    (@(R1)+ - второй операнд X2, результат в X2)

Адрес 03C3: 90    (код операции MOVB)
Адрес 03C4: 91    (источник - (R1), но это не то...)
```

Этот вариант сложный, давайте попробуем проще.

### Вариант Б: Используем регистр для промежуточного хранения

**Шаг 1: Установите регистры**

```
R0 = 000004CF
R1 = 000004D3
R2 = 0000006C
R5 = 00000000  (для хранения результата)
```

**Шаг 2: Программа**

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 55    ((R5) - записать результат в регистр R5)

Адрес 03C4: 94    (MOVB - переместить байт)
Адрес 03C5: 55    (источник (R5))
Адрес 03C6: 52    (назначение (R2) - адрес X3)
```

Но это тоже сложно...

## Вариант В: Проверка формата прямой адресации

Может быть в вашем приложении прямая адресация работает по-другому. Попробуйте:

**Вариант В1:**

```
03C0: C0 90 91 8B 6C
```

**Вариант В2:**

```
03C0: C0 90 91 8F 6C 00
```

**Вариант В3:**

```
03C0: C0 90 91 9F 6C 00 00 00
```

**Вариант В4: Попробуйте использовать режим 4 (автоуменьшение)**

```
03C0: C0 90 91 42  (4×16+2 = 42, но это -(R2), не то)
```

## Вариант Г: Использование другого регистра для результата

Попробуйте использовать R3 вместо R2:

**Шаг 1: Установите**

```
R0 = 000004CF
R1 = 000004D3
R3 = 0000006C  (используем R3 вместо R2!)
```

**Шаг 2: Программа**

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 53    ((R3) вместо (R2))
```

## Вариант Д: Проверка, что записывается в команду

**ВАЖНО:** Проверьте, что именно записано в память по адресам 03C0-03C4:

- 03C0 должно быть: C0
- 03C1 должно быть: 90
- 03C2 должно быть: 91
- 03C3 должно быть: 52 (или другой код, если используете прямую адресацию)

**Может быть проблема в том, что команда записывается неправильно?**

## Вариант Е: Использование косвенной адресации через ПЯ

Попробуйте создать ПЯ3 для адреса X3:

**Шаг 1: Создайте ПЯ3**

```
Адрес 04D7: 6C 00 00 00  (ПЯ3 - адрес X3)
```

**Шаг 2: Установите регистры**

```
R0 = 000004CF
R1 = 000004D3
R2 = 000004D7  (адрес ПЯ3, а не адрес X3!)
```

**Шаг 3: Программа**

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 92    (@(R2)+ - косвенная адресация через ПЯ3)
```
