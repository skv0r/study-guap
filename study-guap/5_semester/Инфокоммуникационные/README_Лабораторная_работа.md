## 💻 Программа

```
Адрес 03C0: C0 90 91 52  ; ADDB3 @(R0)+,@(R1)+,(R2)  → X3 = X1 + X2
Адрес 03C4: D1 54        ; COML (R4)                 → X9 = NOT X9
Адрес 03C6: 7A 53        ; DECW (R3)                 → X6 = X6 - 1
Адрес 03C8: 00           ; HALT
```
