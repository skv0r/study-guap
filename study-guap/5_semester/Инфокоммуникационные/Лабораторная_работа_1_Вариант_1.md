## 1. Перевод исходных данных в шестнадцатеричную систему счисления

### Вычисление исходных данных:

$$
\begin{array}{l}
X1 = (-1)^{1}[(1 + 2) \times 3] = -1 \times 9 = -9 \\
X2 = (-1)^{(1+1)}[(1 + 1) \times 2] = 1 \times 4 = 4 \\
X3 = (-1)^{(1+1)}[1 + 2 + 1 + 21] = 1 \times 25 = 25 \\
X4 = (-1)^{1}[1 + 2 + 29]^{2} = -1 \times 32^{2} = -1024 \\
X5 = (-1)^{(1+1)}[1 + 1 + 23]^{2} = 1 \times 25^{2} = 625 \\
X6 = (-1)^{(1+1)}[1 + 2 + 1 + 79]^{2} = 1 \times 83^{2} = 6889 \\
X7 = X4^{2} = (-1024)^{2} = 1048576 \\
X8 = -X5^{2} = -625^{2} = -390625 \\
X9 = (-1)^{(1+1)} \times X6^{2} = 1 \times 6889^{2} = 47458321
\end{array}
$$

## 4. Текст программы в мнемонических и машинных кодах

### Таблица программы:

| Оператор | Адрес | Шестнадцатеричный код | Мнемонический код        | Комментарий |
| -------- | ----- | --------------------- | ------------------------ | ----------- |
| 1        | 03C0  | C0 90 91 52           | ADDB3 @(R0)+,@(R1)+,(R2) | X3=X1+X2    |
| 2        | 03C4  | D1 54                 | COML (R4)                | X9=NOT X9   |
| 3        | 03C6  | 7A 53                 | DECW (R3)                | X6=X6-1     |
| 4        | 03C8  | 00                    | HALT                     | Останов     |

**Расшифровка кодов операций:**

- `ADDB3` - сложение байтов (3 операнда): код операции C0
- `COML` - инверсия длинного слова: код операции D1
- `DECW` - декремент слова: код операции 7A
- `HALT` - останов: код операции 00

**Форматы адресации VAX-11:**

В VAX-11 формат адресации кодируется как: режим×16 + номер_регистра, где:

- Режим 5 = регистровая адресация (Rn) → код = 50+n
- Режим 6 = регистровая с автоувеличением (Rn)+ → код = 60+n
- Режим 9 = косвенная с автоувеличением @(Rn)+ → код = 90+n

- `@(R0)+` - косвенная адресация с автоувеличением (90 = 9×16 + 0)
- `@(R1)+` - косвенная адресация с автоувеличением (91 = 9×16 + 1)
- `(R2)` - регистровая адресация (52 = 5×16 + 2)
- `(R4)` - регистровая адресация (54 = 5×16 + 4)
- `(R3)` - регистровая адресация (53 = 5×16 + 3)

## 5. Таблица трассировки программы

### Исходное состояние:

**Регистры:**

- R0 = 000004CF (адрес ПЯ1, содержащей адрес X1)
- R1 = 000004D3 (адрес ПЯ2, содержащей адрес X2)
- R2 = 0000006C (адрес X3)
- R3 = 00000072 (адрес X6)
- R4 = 0000007C (адрес X9)

**Память:**

- 006A: F7 (X1 = -9)
- 006B: 04 (X2 = 4)
- 006C: 19 (X3 = 25, исходное значение)
- 0072: 1AE9 (X6 = 6889)
- 007C: 02D42811 (X9 = 47458321)
- 04CF: 0000006A (ПЯ1 - адрес X1)
- 04D3: 0000006B (ПЯ2 - адрес X2)

### Трассировка выполнения:

| Оператор | Операция | Операнд 1 | До операции                  | После операции               | Операнд 2 | До операции                  | После операции               | Операнд 3 | До операции      | После операции       | Результат                     |
| -------- | -------- | --------- | ---------------------------- | ---------------------------- | --------- | ---------------------------- | ---------------------------- | --------- | ---------------- | -------------------- | ----------------------------- |
| 1        | ADDB3    | R0→ПЯ1→X1 | R0=04CF<br>ПЯ1=006A<br>X1=F7 | R0=04D3<br>ПЯ1=006A<br>X1=F7 | R1→ПЯ2→X2 | R1=04D3<br>ПЯ2=006B<br>X2=04 | R1=04D7<br>ПЯ2=006B<br>X2=04 | R2→X3     | R2=006C<br>X3=19 | R2=006C<br>X3=**FB** | X3 = F7 + 04 = FB (-5)        |
| 2        | COML     | R4→X9     | R4=007C<br>X9=02D42811       | R4=007C<br>X9=**FD2BD7EE**   | -         | -                            | -                            | -         | -                | -                    | X9 = NOT(02D42811) = FD2BD7EE |
| 3        | DECW     | R3→X6     | R3=0072<br>X6=1AE9           | R3=0072<br>X6=**1AE8**       | -         | -                            | -                            | -         | -                | -                    | X6 = 1AE9 - 1 = 1AE8 (6888)   |
| 4        | HALT     | -         | -                            | -                            | -         | -                            | -                            | -         | -                | -                    | Останов программы             |

### Детальный расчет операций:

**Операция 1: ADDB3 @(R0)+,@(R1)+,(R2)**

1. Вычисление адреса первого операнда:
   - R0 содержит 04CF
   - Читаем значение из ПЯ1 по адресу 04CF → получаем 0000006A (адрес X1)
   - Увеличиваем R0 на 4 (размер длинного слова) → R0 = 04D3
   - Читаем X1 по адресу 006A → получаем F7 (-9)
2. Вычисление адреса второго операнда:
   - R1 содержит 04D3
   - Читаем значение из ПЯ2 по адресу 04D3 → получаем 0000006B (адрес X2)
   - Увеличиваем R1 на 4 → R1 = 04D7
   - Читаем X2 по адресу 006B → получаем 04 (4)
3. Вычисление результата:
   - F7 + 04 = FB (в байте: -9 + 4 = -5)
   - Записываем FB в X3 по адресу 006C (R2)

**Операция 2: COML (R4)**

- R4 содержит 007C (адрес X9)
- Читаем X9: 02D42811
- Инверсия: NOT(02D42811) = FD2BD7EE
- Записываем FD2BD7EE в X9 по адресу 007C

**Операция 3: DECW (R3)**

- R3 содержит 0072 (адрес X6)
- Читаем X6: 1AE9 (6889)
- Декремент: 1AE9 - 1 = 1AE8 (6888)
- Записываем 1AE8 в X6 по адресу 0072

### Итоговые результаты:

| Переменная | Исходное значение   | Конечное значение        | Изменение                  |
| ---------- | ------------------- | ------------------------ | -------------------------- |
| X1         | F7 (-9)             | F7 (-9)                  | Не изменилось              |
| X2         | 04 (4)              | 04 (4)                   | Не изменилось              |
| X3         | 19 (25)             | **FB (-5)**              | X3 = X1 + X2 = -9 + 4 = -5 |
| X6         | 1AE9 (6889)         | **1AE8 (6888)**          | X6 = X6 - 1                |
| X9         | 02D42811 (47458321) | **FD2BD7EE (-47458322)** | X9 = NOT X9                |
