## 💾 Данные для записи в память

### Операнды:
```
006A: F7           ; X1 = -9
006B: 04           ; X2 = 4
006C: 19           ; X3 = 25 (исходное)
006E: 00 FC        ; X4 = -1024
0070: 71 02        ; X5 = 625
0072: E9 1A        ; X6 = 6889
0074: 00 00 10 00  ; X7 = 1048576
0078: 1F 0A FA FF  ; X8 = -390625
007C: 11 28 D4 02  ; X9 = 47458321
```

### Промежуточные ячейки (ПЯ):
```
04CF: 6A 00 00 00  ; ПЯ1 → адрес X1
04D3: 6B 00 00 00  ; ПЯ2 → адрес X2
```

---

## 🔧 Регистры

```
R0 = 000004CF  ; Адрес ПЯ1
R1 = 000004D3  ; Адрес ПЯ2
R2 = 0000006C  ; Адрес X3
R3 = 00000072  ; Адрес X6
R4 = 0000007C  ; Адрес X9
```

---

## 💻 Программа (машинный код)

```
03C0: C0 90 91 52  ; ADDB3 @(R0)+,@(R1)+,(R2)  → X3 = X1 + X2
03C4: D1 54        ; COML (R4)                 → X9 = NOT X9
03C6: 7A 53        ; DECW (R3)                 → X6 = X6 - 1
03C8: 00           ; HALT
```

---

## ✅ Ожидаемые результаты

| Адрес | Переменная | Ожидаемое значение | Десятичное |
|-------|------------|-------------------|------------|
| 006C  | X3         | **FB**           | -5         |
| 0072  | X6         | **E8 1A**         | 6888       |
| 007C  | X9         | **EE D7 2B FD**   | FD2BD7EE   |

### Финальные значения регистров:
```
R0 = 04D3  (увеличился на 4)
R1 = 04D7  (увеличился на 4)
R2 = 006C  (не изменился)
R3 = 0072  (не изменился)
R4 = 007C  (не изменился)
```

---

## 🔍 Проверка после каждой команды

### После команды 1 (ADDB3):
- R0 = 04D3 ✓
- R1 = 04D7 ✓
- X3 (006C) = FB ✓

### После команды 2 (COML):
- R4 = 007C ✓
- X9 (007C) = EE D7 2B FD ✓

### После команды 3 (DECW):
- R3 = 0072 ✓
- X6 (0072) = E8 1A ✓

---

## ⚠️ Важные замечания

1. **Порядок байтов:** Little-endian (младший байт первым)
2. **Формат ввода:** Шестнадцатеричный (hex)
3. **PC (Program Counter):** Установить на 03C0 перед запуском
4. **Режим выполнения:** Пошаговый (Step-by-step)

---

## 📝 Формулы для проверки

- X3 = X1 + X2 = F7 + 04 = FB (-9 + 4 = -5) ✓
- X9 = NOT(02D42811) = FD2BD7EE ✓
- X6 = 1AE9 - 1 = 1AE8 (6889 - 1 = 6888) ✓
