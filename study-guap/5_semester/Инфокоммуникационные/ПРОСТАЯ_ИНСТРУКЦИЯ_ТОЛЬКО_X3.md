# ПРОСТАЯ ИНСТРУКЦИЯ - ТОЛЬКО X3 = X1 + X2

## Шаг 1: Записать данные в память

Откройте редактор памяти и запишите ТОЛЬКО эти 3 байта:

```
Адрес 006A: F7    (это X1 = -9)
Адрес 006B: 04    (это X2 = 4)
Адрес 006C: 19    (это X3 = 25, исходное значение, будет перезаписано)
```

## Шаг 2: Записать промежуточные ячейки (ПЯ)

Запишите адреса X1 и X2 в промежуточные ячейки:

```
Адрес 04CF: 6A 00 00 00    (это адрес X1 = 006A)
Адрес 04D3: 6B 00 00 00    (это адрес X2 = 006B)
```

**Важно:** Записывайте по 4 байта (длинное слово), младший байт первый.

## Шаг 3: Установить регистры

Установите ТОЛЬКО эти 3 регистра:

```
R0 = 000004CF    (адрес ПЯ1, где лежит адрес X1)
R1 = 000004D3    (адрес ПЯ2, где лежит адрес X2)
R2 = 0000006C    (адрес X3, куда запишется результат)
```

## Шаг 4: Записать программу

**ВАРИАНТ 1: С прямой адресацией результата (попробуйте сначала это)**

Запишите команду с прямой адресацией адреса X3:

```
Адрес 03C0: C0    (код операции ADDB3)
Адрес 03C1: 90    (формат адресации @(R0)+)
Адрес 03C2: 91    (формат адресации @(R1)+)
Адрес 03C3: AF    (прямая адресация, режим 10)
Адрес 03C4: 6C    (младший байт адреса 006C)
Адрес 03C5: 00    (старший байт адреса 006C)
```

**ВАРИАНТ 2: С регистровой адресацией (если вариант 1 не работает)**

```
Адрес 03C0: C0    (код операции ADDB3)
Адрес 03C1: 90    (формат адресации @(R0)+)
Адрес 03C2: 91    (формат адресации @(R1)+)
Адрес 03C3: 52    (формат адресации (R2) - регистровая)
```

**ПРИМЕЧАНИЕ:** Если результат записался не в 006C, попробуйте вариант 1 с прямой адресацией.

## Шаг 5: Выполнить

1. Установите PC (Program Counter) = 03C0
2. Запустите программу (один шаг)
3. Проверьте результат

## Шаг 6: Проверить результат

После выполнения проверьте:

- **X3 (адрес 006C) должно стать: FB**

Это означает: F7 + 04 = FB (то есть -9 + 4 = -5)

---

## Что должно произойти:

1. Команда читает адрес X1 из ПЯ1 (04CF) → получает 006A
2. Увеличивает R0 на 4 → R0 становится 04D3
3. Читает X1 по адресу 006A → получает F7
4. Команда читает адрес X2 из ПЯ2 (04D3) → получает 006B
5. Увеличивает R1 на 4 → R1 становится 04D7
6. Читает X2 по адресу 006B → получает 04
7. Складывает: F7 + 04 = FB
8. Записывает FB в X3 по адресу 006C

---

## ⚠️ ДИАГНОСТИКА ПРОБЛЕМЫ

**Ваш результат:**

- 6A = F7 ✓ (правильно, X1 не изменилось)
- 6B = FB ✗ (должно быть 04, но стало FB - результат записался сюда!)
- 6C = 1D ✗ (должно быть FB, но стало 1D)

**Проблема:** Результат записался в X2 (006B) вместо X3 (006C).

**ВОЗМОЖНЫЕ ПРИЧИНЫ:**

1. **R2 содержит не 006C, а 006B** - проверьте значение R2 ДО выполнения команды!
2. **Формат адресации (R2) работает не так** - может быть нужно использовать другой формат

**ЧТО ПРОВЕРИТЬ ПРЯМО СЕЙЧАС:**

2. Посмотрите, что сейчас в R2 (после выполнения)

**ВРЕМЕННОЕ РЕШЕНИЕ - используйте прямую адресацию:**

Вместо `(R2)` используйте прямой адрес `006C`. Но для этого нужно знать правильный формат прямой адресации в вашем приложении.
