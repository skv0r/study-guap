## 9. Построчный разбор программы

### КОМАНДА 1: Адрес A8

**Код:** `8E 53 98`  
**Мнемоника:** `MNEGB R3 @(R8)+`  
**Комментарий:** X1 = -X2

#### Что делает команда:

MNEGB = Move Negate Byte (переместить отрицание байта)

- Берет байт из источника, вычисляет его отрицание, записывает в приемник

#### Разбор по байтам:

- **8E** = код операции MNEGB
- **53** = операнд 1 (источник): R3 (способ адресации 6 - прямая регистровая)
  - R3 = 0000001C (значение X2 = 28)
  - Берется младший байт: 1C
- **98** = операнд 2 (приемник): @(R8)+ (способ адресации 9)
  - R8 = 00000402 (адрес ПЯ1)
  - @(R8)+ означает:
    1. Взять адрес из R8 (402)
    2. Из ПЯ1 (402) прочитать адрес X1 (0F)
    3. Вычислить отрицание: -1C = E4 (в дополнительном коде)
    4. Записать результат по адресу X1 (0F)
    5. Увеличить R8 на 4 → R8 = 406

#### Результат:

- X1 (адрес 0F) = E4 (hex) = -28 (dec)
- R8 = 00000406

---

### КОМАНДА 2: Адрес AB

**Код:** `C0 98 69`  
**Мнемоника:** `ADDL2 @(R8) (R9)+`  
**Комментарий:** X8 = X8 + X7

#### Что делает команда:

ADDL2 = Add Longword 2 операнда (сложение длинных слов, 2 операнда)

- Складывает два длинных слова, результат записывается во второй операнд

#### Разбор по байтам:

- **C0** = код операции ADDL2
- **98** = операнд 1: @(R8)+ (способ адресации 9)
  - R8 = 00000406 (после команды 1)
  - @(R8)+ означает:
    1. Взять адрес из R8 (406)
    2. Из ПЯ2 (406) прочитать адрес X7 (2D)
    3. Взять значение из X7 (00393100)
    4. Увеличить R8 на 4 → R8 = 40A
- **69** = операнд 2: (R9)+ (способ адресации 7)
  - R9 = 00000037 (адрес X8)
  - (R9)+ означает:
    1. Взять адрес из R9 (37)
    2. Взять значение из X8 (FFE3670F)
    3. Выполнить сложение: 00393100 + FFE3670F = 001C980F
    4. Записать результат обратно в X8 (адрес 37)
    5. Увеличить R9 на 4 → R9 = 3B

#### Результат:

- X8 (адрес 37) = 001C980F
- R8 = 0000040A
- R9 = 0000003B

---

### КОМАНДА 3: Адрес AE

**Код:** `A1 70 52 5C`  
**Мнемоника:** `ADDW3 -(R0) R2 RC`  
**Комментарий:** X6 = X5 + X4

#### Что делает команда:

ADDW3 = Add Word 3 операнда (сложение слов, 3 операнда)

- Складывает два слова, результат записывается в третий операнд

#### Разбор по байтам:

- **A1** = код операции ADDW3
- **70** = операнд 1: -(R0) (способ адресации 8)
  - R0 = 00000025 (начальное значение)
  - -(R0) означает:
    1. Уменьшить R0 на 2 (размер слова) → R0 = 23
    2. Взять адрес из R0 (23)
    3. Взять слово из памяти по адресу 23 = F870 (X4)
- **52** = операнд 2: R2 (способ адресации 6)
  - R2 = 00000559 (значение X5)
  - Берется младшее слово: 0559
- **5C** = операнд 3 (результат): RC (R12, способ адресации 6)
  - RC = 00002341 (начальное значение X6)
  - Выполнить сложение: F870 + 0559 = FDC9
  - Результат записывается в RC

#### Результат:

- RC = 0000FDC9 (X6 = X4 + X5)
- R0 = 00000023

### КОМАНДА 4: Адрес B2

**Код:** `97 91`  
**Мнемоника:** `DECB @(R1)+`  
**Комментарий:** X3 = X3 - 1

#### Что делает команда:

DECB = Decrement Byte (декремент байта)

- Уменьшает байт на 1, результат записывается обратно

#### Разбор по байтам:

- **97** = код операции DECB
- **91** = операнд: @(R1)+ (способ адресации 9)
  - R1 = 0000040C (адрес ПЯ3)
  - @(R1)+ означает:
    1. Взять адрес из R1 (40C)
    2. Из ПЯ3 (40C) прочитать адрес X3 (19)
    3. Взять байт из X3 (25)
    4. Уменьшить на 1: 25 - 1 = 24
    5. Записать результат обратно в X3 (19)
    6. Увеличить R1 на 4 → R1 = 410

#### Результат:

- X3 (адрес 19) = 24
- R1 = 00000410

### КОМАНДА 5: Адрес B4

**Код:** `78 77 69 69`  
**Мнемоника:** `ASHL (R9)+ (R9)+ -(R7)`  
**Комментарий:** X8 = X8 \* 2^X9'

#### Что делает команда:

ASHL = Arithmetic Shift Left (арифметический сдвиг влево)

- Сдвигает длинное слово влево на указанное количество бит (умножение на 2^n)

#### Разбор по байтам:

- **78** = код операции ASHL
- **77** = операнд 1 (счетчик сдвига): -(R7) (способ адресации 8)
  - R7 = 00000042 (адрес X9)
  - -(R7) означает:
    1. Уменьшить R7 на 4 → R7 = 3E
    2. Взять адрес из R7 (42)
    3. Взять значение из X9 (05 - младший байт)
    4. X9' = X9 % 10 = 05 % 10 = 5
- **69** = операнд 2 (значение для сдвига): (R9)+ (способ адресации 7)
  - R9 = 0000003B (после команды 2)
  - НО! R9 должен указывать на X8 (37)
  - (R9)+ означает:
    1. Взять адрес из R9 (37)
    2. Взять значение из X8 (001C980F)
    3. Увеличить R9 на 4 → R9 = 3F
- **69** = операнд 3 (результат): (R9)+ (способ адресации 7)
  - Результат записывается по адресу из R9
  - Выполнить сдвиг: 001C980F << 5 = 039301E0
  - Записать результат в X8 (адрес 37)

#### Результат:

- X8 (адрес 37) = 039301E0
- R7 = 0000003E
- R9 = 0000003F

### КОМАНДА 6: Адрес B8

**Код:** `D8 96 69`  
**Мнемоника:** `ADWC @(R6)+ (R9)+`  
**Комментарий:** X7 = X7 + X8 + C

#### Что делает команда:

ADWC = Add With Carry (сложение с переносом)

- Складывает два длинных слова с учетом флага переноса (Carry), результат записывается во второй операнд

#### Разбор по байтам:

- **D8** = код операции ADWC
- **96** = операнд 1: @(R6)+ (способ адресации 9)
  - R6 = 00000406 (адрес ПЯ2)
  - @(R6)+ означает:
    1. Взять адрес из R6 (406)
    2. Из ПЯ2 (406) прочитать адрес X7 (2D)
    3. Взять значение из X7 (00393100)
    4. Увеличить R6 на 4 → R6 = 40A
- **69** = операнд 2: (R9)+ (способ адресации 7)
  - R9 = 0000003F (после команды 5, но должен указывать на X8 = 37)
  - (R9)+ означает:
    1. Взять адрес из R9 (37)
    2. Взять значение из X8 (039301E0)
    3. Выполнить сложение: 00393100 + 039301E0 + C = 03CC32E0 (если C=0)
    4. Записать результат обратно в X7 (через адрес из ПЯ2)
    5. Увеличить R9 на 4 → R9 = 3B

#### Результат:

- X7 (адрес 2D) = 03CC32E0 (или 03CC32E1, в зависимости от флага переноса C)
- R6 = 0000040A
- R9 = 0000003B

В ходе выполнения данной работы были получены и закреплены навыки работы с ассемблером для процессоров семейства VAX, а в частности работы с процессором VAX-11. Изучены форматы команд и способы адресации процессора VAX-11: прямая регистровая адресация (способ 6), косвенная адресация с автоувеличением (способ 7), косвенная адресация с автоуменьшением (способ 8) и косвенная адресация через память с автоувеличением (способ 9). Освоены различные способы косвенной адресации операндов, включая использование промежуточных ячеек (ПЯ) для хранения адресов операндов, автоматическое изменение регистров при использовании способов адресации с автоувеличением/уменьшением, а также косвенная адресация через память для работы с операндами в памяти. Составлена программа для выполнения алгоритма арифметико-логической обработки данных с реализацией операций отрицания (MNEGB), сложения (ADDL2, ADDW3), декремента (DECB), арифметического сдвига (ASHL) и сложения с переносом (ADWC). Программа протестирована путем ручной трассировки, при этом все результаты выполнения команд совпали с ожидаемыми, а изменения регистров и памяти отслежены на каждом шаге выполнения программы. Изучено представление данных в формате little-endian, где младший байт записывается первым, а длинные слова занимают 4 байта в памяти. Понята структура команд VAX-11, где код операции определяет тип команды, операнды кодируются байтами в зависимости от способа адресации, а размер команды зависит от количества и типов операндов. Работа была выполнена с использованием эмулятора, и запускалась на нем. Были закреплены навыки изучения технической документации, получены навыки работы с различными способами адресации.
