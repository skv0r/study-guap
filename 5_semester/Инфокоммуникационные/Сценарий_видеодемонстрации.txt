СЦЕНАРИЙ ВИДЕОДЕМОНСТРАЦИИ РАБОТЫ СТЕНДА

1. ОБЩИЙ ВИД СХЕМЫ
   - Показать общую топологию сети в Eve-NG
   - Показать все устройства: 4 коммутатора, 2 маршрутизатора, 7 VPC
   - Убедиться, что все устройства запущены и подключены

2. ПРОВЕРКА СВЯЗНОСТИ ВНУТРИ ОДНОГО VLAN

   2.1. VLAN-10 (PC1, PC2, PC3)
   - На VPC1: показать IP-адрес (ip 10.0.10.1/24 10.0.10.254)
   - На VPC1: ping 10.0.10.2 (VPC2) - должен быть успешный ответ
   - На VPC1: ping 10.0.10.3 (VPC3) - должен быть успешный ответ
   - На VPC2: ping 10.0.10.1 (VPC1) - должен быть успешный ответ
   - На VPC2: ping 10.0.10.3 (VPC3) - должен быть успешный ответ

   2.2. VLAN-20 (PC4)
   - На VPC4: показать IP-адрес (ip 10.0.20.1/24 10.0.20.254)
   - Проверить, что VPC4 имеет связь с шлюзом: ping 10.0.20.254

   2.3. VLAN-30 (PC5, PC6)
   - На VPC5: показать IP-адрес (ip 10.0.30.1/24 10.0.30.254)
   - На VPC5: ping 10.0.30.2 (VPC6) - должен быть успешный ответ
   - На VPC6: ping 10.0.30.1 (VPC5) - должен быть успешный ответ

   2.4. VLAN-40 (PC7)
   - На VPC7: показать IP-адрес (ip 10.0.40.1/24 10.0.40.254)
   - Проверить, что VPC7 имеет связь с шлюзом: ping 10.0.40.254

3. ПРОВЕРКА СВЯЗНОСТИ МЕЖДУ РАЗНЫМИ VLAN

   3.1. Из VLAN-10 в другие VLAN
   - На VPC1: ping 10.0.20.1 (VPC4 из VLAN-20) - должен быть успешный ответ
   - На VPC1: ping 10.0.30.1 (VPC5 из VLAN-30) - должен быть успешный ответ
   - На VPC1: ping 10.0.30.2 (VPC6 из VLAN-30) - должен быть успешный ответ

   3.2. Из VLAN-20 в другие VLAN
   - На VPC4: ping 10.0.10.1 (VPC1 из VLAN-10) - должен быть успешный ответ
   - На VPC4: ping 10.0.30.1 (VPC5 из VLAN-30) - должен быть успешный ответ
   - На VPC4: ping 10.0.40.1 (VPC7 из VLAN-40) - должен быть успешный ответ

   3.3. Из VLAN-30 в другие VLAN
   - На VPC5: ping 10.0.10.1 (VPC1 из VLAN-10) - должен быть успешный ответ
   - На VPC5: ping 10.0.20.1 (VPC4 из VLAN-20) - должен быть успешный ответ
   - На VPC5: ping 10.0.40.1 (VPC7 из VLAN-40) - должен быть успешный ответ

   - На VPC7: ping 10.0.30.1 (VPC5 из VLAN-30) - должен быть успешный ответ

4. ПРОВЕРКА ДОСТУПА В ИНТЕРНЕТ

   4.1. С различных VLAN
   - На VPC1: ping 8.8.8.8 - должен быть успешный ответ (доступ в интернет)
   - На VPC4: ping 8.8.8.8 - должен быть успешный ответ
   - На VPC5: ping 8.8.8.8 - должен быть успешный ответ
   - На VPC7: ping 8.8.8.8 - должен быть успешный ответ

   4.2. Проверка NAT на маршрутизаторе
   - На Mikrotik1: показать настройку NAT (ip firewall nat print)
   - Показать, что masquerade настроен на интерфейсе ether1

5. ПРОВЕРКА РАБОТЫ DHCP

   5.1. Получение IP-адреса по DHCP
   - На VPC3: выполнить команду ip dhcp
   - Показать, что VPC3 получил IP-адрес из пула (show ip)
   - Проверить, что получен правильный шлюз и DNS

   5.2. Проверка DHCP-серверов на маршрутизаторах
   - На Mikrotik1: /ip dhcp-server lease print - показать выданные адреса
   - На Mikrotik2: /ip dhcp-server lease print - показать выданные адреса

   5.3. Проверка DHCP на коммутаторах (опционально)
   - На Switch-2: show ip dhcp binding - показать выданные адреса

6. ПРОВЕРКА РАБОТЫ VTP

   6.1. Статус VTP на коммутаторах
   - На Switch-1: show vtp status - показать, что это Primary Server
   - На Switch-2: show vtp status - показать, что это Client и синхронизирован
   - На Switch-3: show vtp status - показать, что это Client и синхронизирован
   - На Switch-4: show vtp status - показать, что это Transparent (если так настроено)

   6.2. Проверка синхронизации VLAN
   - На Switch-1: show vlan brief - показать все VLAN
   - На Switch-2: show vlan brief - показать, что VLAN синхронизированы
   - На Switch-3: show vlan brief - показать, что VLAN синхронизированы

7. ПРОВЕРКА МАРШРУТИЗАЦИИ МЕЖДУ МАРШРУТИЗАТОРАМИ

   7.1. Транзитная сеть VLAN-100
   - На Mikrotik1: /ip address print - показать адрес 192.168.100.1/30 на vlan100
   - На Mikrotik2: /ip address print - показать адрес 192.168.100.2/30 на vlan100
   - На Mikrotik1: /ping 192.168.100.2 count=5 - должен быть успешный ответ

   7.2. Статические маршруты
   - На Mikrotik1: /ip route print - показать маршруты к сетям 10.0.30.0/24 и 10.0.40.0/24 через 192.168.100.2
   - На Mikrotik2: /ip route print - показать маршруты к сетям 10.0.10.0/24 и 10.0.20.0/24 через 192.168.100.1

8. ПРОВЕРКА КОНФИГУРАЦИИ КОММУТАТОРОВ

   8.1. Trunk-порты
   - На Switch-1: show interfaces trunk - показать trunk-порты и разрешенные VLAN
   - На Switch-3: show interfaces trunk - показать trunk-порты
   - На Switch-4: show interfaces trunk - показать trunk-порт к Mikrotik2

   8.2. Access-порты
   - На Switch-2: show vlan brief - показать порты в VLAN-10
   - На Switch-1: show vlan brief - показать порт в VLAN-20
   - На Switch-4: show vlan brief - показать порты в VLAN-30 и VLAN-40

9. ПРОВЕРКА КОНФИГУРАЦИИ МАРШРУТИЗАТОРОВ

   9.1. Mikrotik1
   - Показать VLAN-интерфейсы: /interface vlan print
   - Показать IP-адреса: /ip address print
   - Показать DHCP-серверы: /ip dhcp-server print
   - Показать NAT: /ip firewall nat print

   9.2. Mikrotik2
   - Показать bridge-интерфейсы: /interface bridge print
   - Показать IP-адреса: /ip address print
   - Показать DHCP-серверы: /ip dhcp-server print

10. ФИНАЛЬНАЯ КОМПЛЕКСНАЯ ПРОВЕРКА

    - Выбрать один VPC (например, VPC1)
    - Выполнить ping ко всем остальным VPC:
      * ping 10.0.10.2 (VPC2)
      * ping 10.0.10.3 (VPC3)
      * ping 10.0.20.1 (VPC4)
      * ping 10.0.30.1 (VPC5)
      * ping 10.0.30.2 (VPC6)
      * ping 10.0.40.1 (VPC7)
    - Выполнить ping 8.8.8.8 (интернет)
    - Все пинги должны быть успешными

РЕКОМЕНДАЦИИ ПО СЪЕМКЕ:

1. Начинайте с общего плана схемы, чтобы показать всю топологию
2. Говорите вслух, что вы проверяете (например: "Сейчас проверяю связность внутри VLAN-10")
3. Показывайте команды, которые выполняете
4. Убедитесь, что все пинги успешны перед переходом к следующему пункту
5. Если что-то не работает, покажите это и объясните причину
6. Общая длительность видео должна быть 10-15 минут
7. Можно ускорить части, где просто ждете ответа ping

МИНИМАЛЬНЫЙ НАБОР ДЛЯ БЫСТРОЙ ДЕМОНСТРАЦИИ (5-7 минут):

1. Общий вид схемы (30 сек)
2. Ping внутри VLAN-10: VPC1 → VPC2, VPC3 (30 сек)
3. Ping между VLAN: VPC1 → VPC4 (VLAN-20), VPC1 → VPC5 (VLAN-30), VPC1 → VPC7 (VLAN-40) (1 мин)
4. Ping в интернет: VPC1 → 8.8.8.8 (30 сек)
5. Показать DHCP: VPC3 → ip dhcp, show ip (30 сек)
6. Показать VTP: Switch-1 → show vtp status, Switch-2 → show vtp status (1 мин)
7. Финальная проверка: VPC1 → ping ко всем остальным VPC (1 мин)
