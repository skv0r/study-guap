# РЕШЕНИЕ: Используем прямой адрес вместо регистра

## Проблема

Результат записывается в 006B вместо 006C, даже если R2 = 006C.

**Вывод:** Формат адресации `(R2)` в вашем приложении работает не так, как ожидалось.

## Решение: Используем прямой адрес 006C

Вместо регистровой адресации `(R2)` используем прямой адрес.

### Шаг 1: Восстановите данные

```
Адрес 006B: 04    (восстановить X2)
Адрес 006C: 19    (восстановить исходное X3)
```

### Шаг 2: Новая программа с прямым адресом

**ВАРИАНТ 1: Прямая адресация байта (попробуйте сначала это!)**

```
Адрес 03C0: C0    (код операции ADDB3)
Адрес 03C1: 90    (формат адресации @(R0)+)
Адрес 03C2: 91    (формат адресации @(R1)+)
Адрес 03C3: 8B    (прямая адресация байта, режим 8)
Адрес 03C4: 6C    (адрес 006C - один байт)
```

**ВАРИАНТ 2: Прямая адресация слова (если вариант 1 не работает)**

```
Адрес 03C0: C0    (код операции ADDB3)
Адрес 03C1: 90    (формат адресации @(R0)+)
Адрес 03C2: 91    (формат адресации @(R1)+)
Адрес 03C3: 8F    (прямая адресация слова, режим 8)
Адрес 03C4: 6C    (младший байт адреса 006C)
Адрес 03C5: 00    (старший байт адреса 006C)
```

**ВАРИАНТ 3: Прямая адресация длинного слова (если варианты 1-2 не работают)**

```
Адрес 03C0: C0    (код операции ADDB3)
Адрес 03C1: 90    (формат адресации @(R0)+)
Адрес 03C2: 91    (формат адресации @(R1)+)
Адрес 03C3: 9F    (прямая адресация длинного слова, режим 9)
Адрес 03C4: 6C    (младший байт адреса 006C)
Адрес 03C5: 00    (следующие байты адреса)
Адрес 03C6: 00
Адрес 03C7: 00
```

**ВАРИАНТ 3: Использование другого регистра (R3)**

Попробуйте использовать R3 вместо R2:

```
R3 = 0000006C    (установите R3)
```

И команду:

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 53    ((R3) вместо (R2))
```

### Шаг 3: Регистры

Оставьте регистры как есть:

```
R0 = 000004CF
R1 = 000004D3
R2 = можно не устанавливать (если используете вариант 1 или 2)
R3 = 0000006C (если используете вариант 3)
```

### Шаг 4: Запустите

1. Установите PC = 03C0
2. Запустите команду
3. Проверьте результат в 006C

---

## Попробуйте варианты по порядку:

1. **Сначала вариант 1** (8B 6C) - прямая адресация байта
2. **Если не работает - вариант 2** (8F 6C 00) - прямая адресация слова
3. **Если не работает - вариант 3** (9F 6C 00 00 00) - прямая адресация длинного слова
4. **Если не работает - вариант 4** (R3 вместо R2) - другой регистр

## ВАЖНО: Перед запуском

1. **Восстановите данные:**

   ```
   Адрес 006B: 04
   Адрес 006C: 19
   ```

2. **Установите регистры:**

   ```
   R0 = 000004CF
   R1 = 000004D3
   R2 = можно не устанавливать (для вариантов 1-3)
   R3 = 0000006C (только для варианта 4)
   ```

3. **Запишите программу** (один из вариантов выше)

4. **Установите PC = 03C0**

5. **Запустите и проверьте результат в 006C**
