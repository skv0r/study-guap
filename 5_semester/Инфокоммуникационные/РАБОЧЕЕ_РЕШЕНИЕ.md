# РАБОЧЕЕ РЕШЕНИЕ

## Текущая ситуация

После варианта 1:
- 6A = F7 ✓ (правильно)
- 6B = 04 ✓ (правильно)
- 6C = 19 ✗ (не изменилось - результат НЕ записался!)

Команда выполнилась, но результат не сохранился.

## Решение: Используем ADDB3 с правильной адресацией

Проблема может быть в том, что ADDB2 работает не так. Давайте вернемся к ADDB3, но используем правильный формат.

### Вариант А: ADDB3 с регистром R7

**Шаг 1: Установите регистры**

```
R0 = 000004CF    (адрес ПЯ1)
R1 = 000004D3    (адрес ПЯ2)
R7 = 0000006C    (адрес X3 - используем R7)
```

**Шаг 2: Программа**

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 57    ((R7) - регистровая адресация R7)
```

### Вариант Б: ADDB3 с косвенной адресацией через ПЯ3 (проверенный способ)

**Шаг 1: Создайте ПЯ3**

```
Адрес 04D7: 6C 00 00 00    (адрес X3 = 006C)
```

**ВАЖНО:** Проверьте, что в ПЯ3 записано именно **6C 00 00 00**, а не 6B!

**Шаг 2: Установите регистры**

```
R0 = 000004CF    (адрес ПЯ1)
R1 = 000004D3    (адрес ПЯ2)
R2 = 000004D7    (адрес ПЯ3 - ОБЯЗАТЕЛЬНО 04D7!)
```

**Шаг 3: Программа**

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 92    (@(R2)+)
```

**Шаг 4: Проверьте перед запуском**

- [ ] ПЯ1 (04CF) = 6A 00 00 00
- [ ] ПЯ2 (04D3) = 6B 00 00 00
- [ ] **ПЯ3 (04D7) = 6C 00 00 00** ← ВАЖНО!
- [ ] R0 = 000004CF
- [ ] R1 = 000004D3
- [ ] **R2 = 000004D7** ← ВАЖНО!
- [ ] Программа: 03C0 = C0, 03C1 = 90, 03C2 = 91, 03C3 = 92
- [ ] PC = 03C0

### Вариант В: Используем MOVB для записи результата

Если ADDB3 не работает, попробуем записать результат в регистр, а потом переместить его.

**Шаг 1: Установите**

```
R0 = 000004CF
R1 = 000004D3
R5 = 00000000    (для хранения результата)
R6 = 0000006C    (адрес X3)
```

**Шаг 2: Программа**

```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+ - X1)
Адрес 03C2: 91    (@(R1)+ - X2)
Адрес 03C3: 55    ((R5) - результат в регистр R5)

Адрес 03C4: 94    (MOVB - переместить байт)
Адрес 03C5: 55    (источник (R5))
Адрес 03C6: 56    (назначение (R6) - адрес X3)
```
