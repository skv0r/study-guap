# ФИНАЛЬНОЕ РЕШЕНИЕ: Используем косвенную адресацию для результата

## Идея

Если `@(R0)+` и `@(R1)+` работают правильно, давайте используем такую же косвенную адресацию для результата!

## Решение: Косвенная адресация через ПЯ3

### Шаг 1: Восстановите данные

```
Адрес 006B: 04    (восстановить X2)
Адрес 006C: 19    (восстановить исходное X3)
```

### Шаг 2: Создайте ПЯ3 для адреса X3

```
Адрес 04D7: 6C 00 00 00    (ПЯ3 - адрес X3 = 006C)
```

**Важно:** Записывайте по 4 байта, младший байт первый (как ПЯ1 и ПЯ2).

### Шаг 3: Установите регистры

```
R0 = 000004CF    (адрес ПЯ1)
R1 = 000004D3    (адрес ПЯ2)
R2 = 000004D7    (адрес ПЯ3 - НЕ адрес X3!)
```

**ВАЖНО:** R2 теперь содержит адрес ПЯ3, а не адрес X3!

### Шаг 4: Новая программа

```
Адрес 03C0: C0    (код операции ADDB3)
Адрес 03C1: 90    (формат адресации @(R0)+)
Адрес 03C2: 91    (формат адресации @(R1)+)
Адрес 03C3: 92    (формат адресации @(R2)+)
```

**Объяснение:**
- `@(R0)+` - читает адрес X1 из ПЯ1, увеличивает R0
- `@(R1)+` - читает адрес X2 из ПЯ2, увеличивает R1
- `@(R2)+` - читает адрес X3 из ПЯ3, увеличивает R2, записывает результат в X3

### Шаг 5: Запустите

1. Установите PC = 03C0
2. Запустите команду
3. Проверьте результат в 006C

---

## Ожидаемый результат

После выполнения:
- 6A = F7 ✓ (не изменилось)
- 6B = 04 ✓ (не изменилось)
- 6C = **FB** ✓ (результат!)
- R0 = 04D3 (увеличился на 4)
- R1 = 04D7 (увеличился на 4)
- R2 = 04DB (увеличился на 4)

---

## Если это не работает

Попробуйте использовать R3 вместо R2:

**Шаг 3 (альтернатива):**
```
R0 = 000004CF
R1 = 000004D3
R3 = 000004D7    (используем R3 вместо R2)
```

**Шаг 4 (альтернатива):**
```
Адрес 03C0: C0    (ADDB3)
Адрес 03C1: 90    (@(R0)+)
Адрес 03C2: 91    (@(R1)+)
Адрес 03C3: 93    (@(R3)+)
```

---
