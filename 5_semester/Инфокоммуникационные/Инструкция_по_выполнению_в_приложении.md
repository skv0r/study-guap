# Подробная инструкция по выполнению лабораторной работы в приложении VAX-11

**Вариант:** 1  
**Номер группы:** 21  
**Исходные данные:** NV=1, NGL=1, NGP=2  
**Алгоритм:** X3=X1+X2, X9=NOT X9, X6=X6-1

---

## Подготовка к работе

### Шаг 1: Открытие приложения

1. Запустите симулятор VAX-11
2. Создайте новый проект или откройте существующий
3. Убедитесь, что память доступна (по умолчанию 2 КБ, адреса 0-7FF)
4. Очистите память и регистры (если требуется)

### Шаг 2: Запись исходных данных в память

**Как записать данные:**

1. Найдите в интерфейсе приложения режим редактирования памяти (обычно называется "Memory Editor", "Память" или "Memory")
2. Введите адрес в шестнадцатеричном формате (например, 006A)
3. Введите значение байта/слова/длинного слова в шестнадцатеричном формате
4. Подтвердите ввод

**Данные для записи (формат: младший байт первый для многобайтовых значений):**

```
Адрес 006A: F7                    ; X1 = -9 (байт)
Адрес 006B: 04                    ; X2 = 4 (байт)
Адрес 006C: 19                    ; X3 = 25 (байт, исходное значение)
Адрес 006E: 00 FC                 ; X4 = -1024 (слово, младший байт первый)
Адрес 0070: 71 02                 ; X5 = 625 (слово, младший байт первый)
Адрес 0072: E9 1A                 ; X6 = 6889 (слово, младший байт первый)
Адрес 0074: 00 00 10 00           ; X7 = 1048576 (длинное слово)
Адрес 0078: 1F 0A FA FF           ; X8 = -390625 (длинное слово)
Адрес 007C: 11 28 D4 02           ; X9 = 47458321 (длинное слово)
```

**Важно:**

- В VAX-11 используется порядок байтов "little-endian" (младший байт по младшему адресу)
- Для слов (2 байта): младший байт записывается первым
- Для длинных слов (4 байта): младший байт записывается первым
- Пример: X6 = 6889 = 1AE9 (hex) → в памяти: E9 1A (младший байт E9 по адресу 0072, старший байт 1A по адресу 0073)

#### Промежуточные ячейки (ПЯ) для косвенной адресации:

```
Адрес 04CF: 6A 00 00 00           ; ПЯ1 - адрес X1 (длинное слово)
Адрес 04D3: 6B 00 00 00           ; ПЯ2 - адрес X2 (длинное слово)
```

### Шаг 3: Инициализация регистров

**Как установить значения регистров:**

1. Найдите в интерфейсе приложения окно регистров (обычно называется "Registers", "Регистры" или "Register Window")
2. Выберите нужный регистр (R0, R1, R2, R3, R4)
3. Введите значение в шестнадцатеричном формате (можно с ведущими нулями или без)
4. Подтвердите ввод

**Значения регистров для установки:**

```
R0 = 000004CF  (адрес ПЯ1, которая содержит адрес X1)
R1 = 000004D3  (адрес ПЯ2, которая содержит адрес X2)
R2 = 0000006C  (адрес X3 - результат операции сложения)
R3 = 00000072  (адрес X6 - для операции декремента)
R4 = 0000007C  (адрес X9 - для операции инверсии)
```

**Примечание:** Некоторые приложения могут требовать ввод без ведущих нулей (например, 4CF вместо 000004CF). Проверьте формат ввода в вашем приложении.

### Шаг 4: Запись программы в память

**Способ 1: Запись машинных кодов (рекомендуется)**

Запишите команды программы, начиная с адреса **03C0**, байт за байтом:

```
Адрес 03C0: C0                    ; Код операции ADDB3
Адрес 03C1: 90                    ; @(R0)+ - косвенная адресация с автоувеличением
Адрес 03C2: 91                    ; @(R1)+ - косвенная адресация с автоувеличением
Адрес 03C3: 52                    ; (R2) - регистровая адресация

Адрес 03C4: D1                    ; Код операции COML
Адрес 03C5: 54                    ; (R4) - регистровая адресация

Адрес 03C6: 7A                    ; Код операции DECW
Адрес 03C7: 53                    ; (R3) - регистровая адресация

Адрес 03C8: 00                    ; Код операции HALT
```

**Способ 2: Ввод мнемоник (если приложение поддерживает)**

Если ваше приложение поддерживает ввод мнемонических кодов, используйте:

```
03C0: ADDB3 @(R0)+,@(R1)+,(R2)
03C4: COML (R4)
03C6: DECW (R3)
03C8: HALT
```

**Как записать:**

1. Перейдите в режим редактирования памяти
2. Введите адрес 03C0
3. Запишите каждый байт последовательно (C0, затем 90, затем 91, и т.д.)
4. Или используйте функцию ввода команды целиком (если доступна)

**Проверка записи:**
После записи проверьте, что в памяти по адресам 03C0-03C8 находятся правильные значения:

- 03C0: C0 90 91 52
- 03C4: D1 54
- 03C6: 7A 53
- 03C8: 00

### Шаг 5: Сохранение программы

1. Сохраните программу в файл с расширением `.v11`
2. Рекомендуемое имя: `lab1_var1_group21.v11`
3. Убедитесь, что сохранены все данные, регистры и команды

## Выполнение программы

### Шаг 6: Настройка выполнения

**Перед запуском программы:**

1. **Установите начальный адрес выполнения (Program Counter / PC):**

   - Найдите поле "PC", "Program Counter" или "Адрес выполнения"
   - Установите значение: **03C0**
   - Это адрес первой команды программы

2. **Установите режим пошагового выполнения:**

   - Найдите переключатель режима выполнения
   - Выберите "Step-by-step", "Пошагово" или "Single Step"
   - Это позволит выполнять программу по одной команде

3. **Проверьте инициализацию:**
   - Проверьте значения всех регистров (R0-R4)
   - Проверьте данные в памяти (006A-007C для операндов, 04CF-04D3 для ПЯ)
   - Проверьте программу в памяти (03C0-03C8)

**Важно:** Убедитесь, что все данные записаны правильно перед запуском!

### Шаг 7: Пошаговое выполнение

Выполняйте программу по одной команде, проверяя результаты после каждого шага:

#### Команда 1: ADDB3 @(R0)+,@(R1)+,(R2) (адрес 03C0)

**До выполнения:**

- R0 = 04CF
- R1 = 04D3
- R2 = 006C
- X1 (006A) = F7
- X2 (006B) = 04
- X3 (006C) = 19

**Процесс выполнения:**

1. Читаем адрес из ПЯ1 (04CF) → получаем 0000006A
2. Увеличиваем R0 на 4 → R0 = 04D3
3. Читаем X1 по адресу 006A → получаем F7 (-9)
4. Читаем адрес из ПЯ2 (04D3) → получаем 0000006B
5. Увеличиваем R1 на 4 → R1 = 04D7
6. Читаем X2 по адресу 006B → получаем 04 (4)
7. Вычисляем: F7 + 04 = FB (-5)
8. Записываем FB в X3 по адресу 006C

**После выполнения:**

- R0 = 04D3 (увеличился на 4)
- R1 = 04D7 (увеличился на 4)
- R2 = 006C (не изменился)
- X3 (006C) = **FB** (-5) ✓

#### Команда 2: COML (R4) (адрес 03C4)

**До выполнения:**

- R4 = 007C
- X9 (007C) = 02D42811

**Процесс выполнения:**

1. Читаем X9 по адресу 007C → получаем 02D42811
2. Выполняем побитовую инверсию: NOT(02D42811) = FD2BD7EE
3. Записываем результат обратно в X9

**После выполнения:**

- R4 = 007C (не изменился)
- X9 (007C) = **FD2BD7EE** (инверсия исходного значения) ✓

#### Команда 3: DECW (R3) (адрес 03C6)

**До выполнения:**

- R3 = 0072
- X6 (0072) = 1AE9 (6889)

**Процесс выполнения:**

1. Читаем X6 по адресу 0072 → получаем 1AE9 (6889)
2. Уменьшаем на 1: 1AE9 - 1 = 1AE8 (6888)
3. Записываем результат обратно в X6

**После выполнения:**

- R3 = 0072 (не изменился)
- X6 (0072) = **1AE8** (6888) ✓

#### Команда 4: HALT (адрес 03C8)

Программа останавливается.

## Отладка (если результаты не совпадают)

### Возможные проблемы:

1. **Неправильная инициализация данных:**

   - Проверьте, что все данные записаны в правильные адреса
   - Убедитесь в правильности порядка байтов (little-endian)

2. **Неправильная инициализация регистров:**

   - Проверьте начальные значения всех регистров
   - Убедитесь, что R0 и R1 указывают на правильные ПЯ

3. **Неправильные коды операций:**

   - Проверьте коды операций в памяти
   - Убедитесь в правильности форматов адресации

4. **Ошибки в трассировке:**
   - Выполните программу по шагам еще раз
   - Сравните каждый шаг с таблицей трассировки из отчета

## Дополнительные советы

1. **Используйте точки останова (breakpoints):**

   - Установите точки останова перед каждой командой (03C0, 03C4, 03C6)
   - Это позволит останавливать выполнение перед каждой операцией для проверки состояния

2. **Просмотр памяти:**

   - Регулярно проверяйте содержимое памяти в области данных (006A-007C)
   - Проверяйте промежуточные ячейки (04CF-04D3)
   - Используйте функцию "Watch" или "Наблюдение" для отслеживания изменений

3. **Журнал выполнения:**

   - Если приложение поддерживает, включите журнал выполнения (execution log)
   - Это поможет отследить все изменения регистров и памяти

4. **Снимки состояния:**

   - Делайте снимки состояния (snapshots) до и после выполнения каждой команды
   - Это позволит легко вернуться к предыдущему состоянию при необходимости

5. **Проверка форматов:**

   - Убедитесь, что при просмотре памяти вы видите значения в правильном формате (hex)
   - Проверьте, что порядок байтов соответствует little-endian

6. **Документирование:**
   - Записывайте фактические значения после каждой команды
   - Сравнивайте с ожидаемыми результатами из трассировки
