# Переход между чатами Codex

Этот файл переносит краткий рабочий контекст двух важных локальных чатов Windows. Он не импортирует их полную историю, вложения или состояние инструментов. На Mac откройте новый чат Codex в клоне `study-guap` и приложите нужный файл ниже.

## Чаты

- **guap-bisness** — [контекст](7_semester/Основы%20бизнеса/CODEX_CHAT_HANDOFF.md). Исходный чат Windows: `01a1e64d-240c-79c2-952f-56db3d0762c1`.
- **guap-labs** — [контекст ЛР7 СТЗ](7_semester/Системы%20технического%20зрения%20на%20производстве/ЛР7/CODEX_CHAT_HANDOFF.md). Исходный чат Windows: `01a1e64d-23ff-78f1-a91c-2b35474c47b4`.

## На Mac

1. Выполните `git pull` в клоне `study-guap`.
2. Откройте папку репозитория в Codex.
3. Для каждого направления создайте отдельный чат и приложите соответствующий `CODEX_CHAT_HANDOFF.md`.
4. Продолжайте работу в новом чате. Чтобы передать новые договорённости обратно на Windows, обновляйте handoff-файл и отправляйте изменения через Git.

Если чат `guap-labs` работал из отдельного клона `pairwise`, откройте его на Mac отдельно; актуальные файлы ЛР7 и handoff находятся в `study-guap`.
