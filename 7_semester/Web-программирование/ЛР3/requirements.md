Источник: `C:\Users\skvor\OneDrive\Desktop\LR3Клиентская_часть_фото_модальные_окна.pdf`.

Тема: «Реализация клиентской части веб-приложения: фотографии, модальные окна, бургер-меню, состояние пользователя и карта».

Сдача: код в репозитории pairwise, ветка `lr3/gallery-modal-map`, без слияния в main. Отчёт Word. Преподаватель: ассистент В.В. Жукалин. Студент Г.В. Буренков, группа 4321.

Код пишет студент в обычном режиме. В этой работе код сделан по прямой просьбе: дедлайн, стиль PairWise (4 пробела, стрелочные компоненты, BEM, русский интерфейс, `useDemoAuth`). Пример методички (StudySpace / TheraCity, `places.ts`, Москва) не копировать.

Обязательный код:

- у площадки есть фото, alt, широта и долгота; локальные файлы в `public/images/spots`; вывод через `next/image`;
- страница `/gallery`: серверный `page.tsx` и клиентская галерея;
- выбранная карточка в `useState`; модальное окно через `createPortal` в `document.body`;
- `role="dialog"`, `aria-modal`, `aria-labelledby`, видимое закрытие, Escape, щелчок только по подложке, фокус внутрь, цикл Tab, возврат фокуса, блокировка прокрутки, cleanup;
- бургер вместо меню шапки: `aria-expanded`, `aria-controls`, `usePathname`, ссылки на главную, каталог, галерею, о проекте и кабинет; гость видит вход, пользователь — имя и выход; закрытие по ссылке, Escape и подложке;
- избранное: `Set` идентификаторов в `useState`; гость видит ссылку на вход; надпись, что избранное живёт до обновления страницы; без `localStorage`;
- Яндекс Карты JS API 2.1: ключ `NEXT_PUBLIC_YANDEX_MAPS_API_KEY`, `ymaps.ready`, метка на каждую площадку, подсказка — название, щелчок открывает то же окно, `destroy` в cleanup; без ключа — понятное сообщение. Ключ в репозиторий не класть.

Шапка по-прежнему показывает «Вход». Пароль в состояние не пишется.

Содержание отчёта — пункты раздела 7 методички. Раздел 8 методички — источники самой методички, в отчёт списком не переносить.

Критерий готовности: `npm run lint` и `npm run build` без ошибок, сценарии гостя и пользователя проверены в браузере, отчёт описывает фактический код.
