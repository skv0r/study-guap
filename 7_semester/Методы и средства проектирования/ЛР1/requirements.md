# ЛР1 (методичка: лабораторная работа 9)

Сдать: Word `ЛР1_Отчет_Буренков_МиСП.docx`.

Предмет: Методы и средства проектирования информационных систем и технологий. Преподаватель с прошлогоднего титула: доцент, канд. техн. наук А. В. Бржезовский. Группа 4321, Г.В. Буренков, кафедра 42, 2026.

СУБД: PostgreSQL. Предметная область — вариант 5 (вуз, факультет, группа, студент, конференция, программа, выступление, участие). Не SQL Server.

Обязательно по п. 9.6:
- сгенерировать и вставить тестовые данные;
- выполнить запросы из прошлогодних ЛР3–ЛР5 (или аналогичные);
- зафиксировать планы и время;
- создать индексы по рекомендациям п. 9.2;
- повторить запросы, зафиксировать планы и время;
- сопоставить планы;
- вместо hints MS SQL — EXPLAIN (ANALYZE, BUFFERS) и enable_seqscan / enable_indexscan / enable_nestloop / enable_hashjoin.

Содержание отчёта: операторы создания индексов; планы и время до, после и с параметрами планировщика; явное сопоставление планов по случаям (таблицы узлов плана до/после индексов и при enable_seqscan / enable_indexscan / enable_nestloop / enable_hashjoin) с описанием изменений.

Критерий «сделано»: числа и планы сняты с работающего сервера, не выдуманы. Список источников не добавлять. В тексте нет имён скриптов сборки и путей диска.
