# ЛР7. Разбор трёх алгоритмов

Задание преподавателя: самостоятельно, с применением трансформеров и нейросетей, составить и сгенерировать пример разбора трёх типов алгоритмов на свой выбор. Всё в одном файле. По отчёту будет защита на понимание. Пример оформления — лекция по CART; сам CART и пример с доходом не копировать.

Сдать один файл: `ЛР7_Отчет_Буренков_МИИ.docx`. Титул бланка ЛР1, номер 7, тема «ТРИ АЛГОРИТМА КЛАССИФИКАЦИИ», преподаватель В.В. Фомин. Списка источников нет.

Три типа, которые можно повторить на доске: метод k ближайших соседей, наивный Байес по одному признаку, один нейрон (перцептрон) с явными весами. Предмет — мячи, короткие свои наборы, не таблица из 150 строк и не iris. Каждое число считается скриптом и попадает в текст из этого расчёта.

Сделано, если в файле три разных алгоритма, у каждого формула, таблица и пошаговый счёт, и по тексту можно заново получить тот же класс.
