Обязательные шаги работы № 3:

1. Прочитать свой CSV.
2. Назначить цвет классов для диаграммы.
3. Разбиение 70 % / 30 %, стратификация по классу.
4. Дерево решений: атрибут класса, критерий разбиения (Джини), ограничение глубины (4), в листе не меньше 3 наблюдений.
5. Прогноз на тесте, матрица ошибок, accuracy, precision, recall, F-measure.
6. Визуализация дерева и логические правила листьев с физическим пояснением порогов.
7. Диаграмма рассеяния.

Данные свои: мяч, три класса (футбольный, баскетбольный, волейбольный), 150 строк, по 50 в классе. Типовой набор — центр класса; строки с разбросом, точных копий нет. Признаки — реальные измерения без кодирования 0/1/2 и без таблицы расшифровки: коэффициент упругости, окружность (см), масса (г), давление (бар), высота контрольного отскока (см). Не iris. Общий файл `data/balls.csv`, то же разбиение 70/30: обучение 105 (по 35), тест 45 (по 15). Один общий тест с ЛР2/4/5. Номер наблюдения в модель не входит. Старый `tickets.csv` не удалять. Файл `requests.csv` в ЛР2 не удалять.
