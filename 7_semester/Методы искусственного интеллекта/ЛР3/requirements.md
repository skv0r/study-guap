# ЛР3 МИИ. Требования

Источник: Фомин В. В., Ветрова Ю. В. Методы машинного обучения: лаб. практикум. СПб.: ГУАП, 2024. Работа № 3 «Метод дерева решений».

Сдать: отчёт Word `ЛР3_Отчет_Буренков_МИИ.docx`. Формулировка задания, входные данные текстом, ход, выводы. Список источников не добавлять.

Обязательные шаги работы № 3:

1. Прочитать свой CSV.
2. Назначить цвет классов для диаграммы.
3. Разбиение 70 % / 30 %, стратификация по классу.
4. Дерево решений: атрибут класса, критерий разбиения, ограничение глубины против переобучения.
5. Прогноз на тесте, матрица ошибок, accuracy, precision, recall, F-measure.
6. Визуализация дерева и логические правила листьев.
7. Диаграмма рассеяния.

Данные свои: обращения в IT-поддержку, тип инцидента из трёх классов (сеть / доступ / ПО), четыре числовых признака, 90 строк. Не копировать iris. Набор общий для последующих работ по классификации (байес, SVM и сравнение с k-NN).

Инструмент: Python. Те же шаги, без рисунков интерфейса KNIME.

Каркас: 1 Задание, 2 Входные данные, 3 Ход выполнения работы, 4 Выводы.

Титул: профессор, д-р техн. наук, профессор В.В. Фомин. Тема: МЕТОД ДЕРЕВА РЕШЕНИЙ. Курс: Методы искусственного интеллекта. Группа 4321, Г.В. Буренков. Номер работы 3.
