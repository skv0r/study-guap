Обязательные шаги работы № 1:

1. Прочитать свой CSV.
2. Назначить цвет классов для диаграммы.
3. Разбиение 70 % / 30 %, стратификация по классу.
4. k ближайших соседей. k выбрать только по обучению, нечётные значения, объяснить выбор. Евклидово расстояние. Признаки перед расстоянием привести к одному масштабу по обучающей выборке.
5. Оценка классификатора: матрица ошибок, accuracy, precision, recall, F-measure.
6. Диаграмма рассеяния.

Данные свои и общие с ЛР3–ЛР5: мяч, три класса (футбольный, баскетбольный, волейбольный), 150 строк, по 50 в классе. Признаки — реальные измерения без кодирования 0/1/2 и без таблицы расшифровки: коэффициент упругости, окружность (см), масса (г), давление (бар), высота контрольного отскока (см). Типовой набор — центр класса; строки с разбросом, точных копий нет. Файл `data/balls.csv` — копия набора из ЛР3. То же разбиение: в обучении 105, в тесте 45, в каждом классе 35 и 15. Один общий тест. Номер наблюдения в модель не входит. Перед евклидовым расстоянием признаки стандартизируются по обучению (разброс в реальных единицах разный: граммы, сантиметры, безразмерная упругость). Не копировать iris и старый текст про коды розыгрыша. Файл `requests.csv` не удалять.

Инструмент: Python. Те же шаги, без рисунков интерфейса KNIME.
