# ЛР1 МИИ. Требования

Источник: Фомин В. В., Ветрова Ю. В. Методы машинного обучения: лаб. практикум. СПб.: ГУАП, 2024. Работа № 2 «Метод линейной регрессии».

Сдать: отчёт Word. В нём формулировка задания, входные данные текстом, ход (сценарий и результаты), выводы.

Обязательные шаги работы № 2:

1. Прочитать свой CSV.
2. Назначить цвет наблюдениям для диаграммы.
3. Partitioning: 20 % в первую (обучающую) выборку, способ — линейная выборка, не «первые строки».
4. Линейная регрессия: целевой столбец и один независимый признак, константа сохраняется.
5. Прогноз: к тестовым строкам добавляется столбец прогноза.
6. Числовые показатели: R², средняя абсолютная ошибка, среднеквадратичная ошибка, корень из неё, средняя разность со знаком, средняя абсолютная процентная ошибка, скорректированный R².
7. Диаграмма рассеяния: по горизонтали независимая переменная, по вертикали отклик.

По сданному отчёту Евстафьевой дополнительно: округление прогноза до целой минуты и исключение дробного столбца из таблицы результата. Чужие данные (столовая, salary, iris) не использовать.

Инструмент: Python. Те же шаги, без рисунков интерфейса KNIME.

Сделано, если есть своё уравнение, показатели на тестовой части и диаграмма, а числа в тексте совпадают с расчётом.
