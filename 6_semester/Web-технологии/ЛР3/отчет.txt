1. Цель работы
	Изучение HTML-тегов для построения таблиц различной сложности и освоение CSS-свойств для управления фоном (background) веб-страниц и отдельных элементов.

2. Задание
	Создать HTML-страницу, содержащую таблицу. При создании таблицы использовать теги объединения ячеек по строкам (rowspan) и по столбцам (colspan), добавить заголовок таблицы (caption), а также сгруппировать строки с помощью тегов thead, tbody, tfoot. Продемонстрировать стилизацию столбцов с помощью тегов colgroup и col. Применить CSS-свойства оформления для таблиц (border-collapse, отступы, границы ячеек) и реализовать чередующийся цвет строк таблиц (чересстрочный фон) с помощью псевдоклассов, а также подсветку строки при наведении мыши. Настроить сложный фон для веб-страницы: использовать линейный градиент в качестве фонового изображения, задать цвет фона по умолчанию и зафиксировать фон при прокрутке страницы. Добавить ссылки навигации между всеми страницами работы.

3. Вывод
	В ходе лабораторной работы были получены практические навыки верстки HTML-таблиц. Были успешно применены элементы структурирования таблиц (thead, tbody, tfoot, caption, colgroup), реализовано объединение ячеек с помощью атрибутов rowspan и colspan. С помощью каскадных таблиц стилей (CSS) выполнено детальное оформление таблицы: задан стиль границ, отступы, чересстрочная заливка и эффект подсветки при наведении (:hover). Помимо этого, закреплены навыки работы с фоном элементов: для веб-страницы установлен сложный градиентный фон (linear-gradient), зафиксированный относительно окна браузера (background-attachment: fixed). Интеграция новой страницы в существующий проект выполнена успешно с помощью перекрестных навигационных ссылок. Поставленные цели работы достигнуты в полном объеме.
