1. Цель работы
	С использованием библиотек языка JavaScript научиться создавать анимационные эффекты и строить графики на веб-странице.

2. Задание
	1) Создать на веб-странице анимационный эффект с заданием параметров анимации (длительность, функция плавности и др.).
	2) Поместить на веб-страницу график (диаграмму), отображающий данные в соответствии с выбранной тематикой.
	Выполнен вариант 1: самые популярные веб-браузеры в мире.

3. Вывод
	В ходе лабораторной работы были освоены приемы применения внешних JavaScript-библиотек для решения практических задач пользовательского интерфейса. С использованием jQuery реализована анимация элемента с управлением длительностью и функцией плавности, а с использованием Chart.js построена столбчатая диаграмма для визуализации тематических данных. Поставленная цель по изучению библиотек JavaScript для анимации и визуализации данных достигнута.
