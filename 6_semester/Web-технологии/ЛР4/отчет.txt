1. Цель работы
	Изучение HTML-тегов для создания интерактивных веб-форм и средств CSS для их визуального оформления. Ознакомление с различными типами полей ввода данных (Text, Password, Radio, Checkbox, Select, Textarea, Button).

2. Задание
	Создать HTML-страницу, содержащую регистрационную форму. Продемонстрировать применение тега <form> и логическую группировку элементов формы с использованием тегов <fieldset> и <legend>. Реализовать текстовые поля ввода (<input type="text">), поле для ввода пароля (<input type="password">), группы радио-кнопок для выбора одного варианта из нескольких (<input type="radio">), независимые флажки-переключатели (<input type="checkbox">). Подключить выпадающий список вариантов выбора (<select> и <option>). Добавить многострочное текстовое поле (<textarea>). Реализовать кнопки для отправки формы (type="submit") и для сброса введенных значений (type="reset"). Применить атрибуты, такие как required и placeholder. Настроить CSS-стили для улучшения внешнего вида всех элементов управления и их выравнивания на странице.

3. Вывод
	В ходе лабораторной работы были получены практические навыки разработки и компоновки HTML-форм. Успешно применены все основные типы полей ввода (input), что позволяет собирать различную информацию: текстовые данные, логические метки, уникальный и множественный выбор. Применение тегов fieldset и legend помогло семантически структурировать группы данных формы. Настроены механизмы валидации на стороне клиента (required) и контекстные подсказки (placeholder). Применение технологии CSS обеспечило аккуратный современный внешний вид элементов формы: заданы рамки, внутренние отступы, тени, а также стилизованы кнопки отправки и сброса. Поставленные цели работы достигнуты в полном объеме.
