1. Цель работы
	Изучение технологии создания двумерных макетов CSS Grid Layout для верстки современных, масштабируемых и сложных веб-страниц.

2. Задание
	Разработать веб-страницу, макет которой полностью построен на основе CSS сетки (display: grid). Сформировать классическую структуру страницы: шапка (header), боковое навигационное меню (nav), основная область с контентом (main), дополнительная колонка (aside) и подвал (footer). Присвоить каждому смысловому блоку имя с помощью свойства grid-area. Спроектировать контейнер сетки с использованием свойства grid-template-areas, визуально задав двумерное расположение элементов. Настроить размеры столбцов и строк с применением grid-template-columns и grid-template-rows, а также зазоры между ячейками (gap). Дополнительно продемонстрировать использование вложенных сеток на примере "галереи" внутри центрального контента с функцией repeat(auto-fit, minmax(...)).

3. Вывод
	В ходе лабораторной работы были освоены принципы создания макетов с помощью CSS Grid. Данная технология позволяет максимально наглядно описывать каркас сайта с использованием именованных областей (grid-template-areas), что делает код интуитивно понятным и легко читаемым. Построение макета потребовало минимальных усилий: всего несколько строк кода позволили разместить шапку, меню, контент, виджеты и подвал в нужных местах экрана. Также была изучена мощная функция `repeat` в комбинации с `auto-fit` и `minmax`, позволяющая создавать "резиновые" галереи внутренних элементов без медиазапросов. Поставленная цель по освоению grid-верстки достигнута.
