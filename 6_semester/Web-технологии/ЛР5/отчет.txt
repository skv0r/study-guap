1. Цель работы
	Изучение технологии создания гибких макетов Flexbox (Flexible Box Layout) для верстки современных, семантико-ориентированных и адаптивных веб-страниц.

2. Задание
	Разработать макет веб-страницы с применением семантических тегов HTML5 (header, nav, main, aside, footer). Собрать макет при помощи технологии CSS Flexbox, полностью отказавшись от использования таблиц, float и абсолютного позиционирования для создания сетки. Настроить гибкий контейнер-обертку на распределение пространства по вертикали. Настроить область контента так, чтобы левая колонка (основной контент) и правая колонка (сайдбар) распределялись в соотношении 3:1 соответственно. Применить свойства justify-content, align-items, flex-wrap, flex-direction и flex-basis для расположения элементов меню и внутренних блоков (карточек) на странице. 

3. Вывод
	В ходе лабораторной работы были получены навыки использования современного стандарта Flexbox для построения каркаса страницы. Главное преимущество Flexbox заключается в простом и предсказуемом выравнивании элементов как по вертикали, так и по горизонтали. Путем манипуляции свойством flex была без усилий сформирована двухколоночная структура с панелью навигации и подвалом, прижатым к низу страницы. Использование свойства flex-wrap позволило сделать макет отзывчивым, так как внутренние блоки (карточки) автоматически переносятся на новую строку при нехватке ширины экрана экрана, а свойство gap решило проблему распределения отступов между ними. Поставленная цель по освоению флексбокс-верстки достигнута.
