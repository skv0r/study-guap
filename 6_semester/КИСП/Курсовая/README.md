# Курсовая работа: Бронирование компьютерного клуба (1С:Предприятие 8.3/8.5)

В данном репозитории находится итоговая версия конфигурации 1С для управления компьютерным клубом. Проект включает в себя учет компьютеров, тарифов, клиентов, бронирование сеансов, складской учет (бар), финансовые отчеты и бизнес-процессы обслуживания.

## Структура репозитория

- `src/` — исходные XML-файлы конфигурации (выгрузка).
- `КурсоваяИТОГ.dt` — итоговый дамп информационной базы (содержит конфигурацию и тестовые данные).
- `InfoBase/` — папка файловой базы данных 1С (можно использовать для локального запуска).
- `Posobie.pdf` — методическое пособие.
- Документация в папках `Требования/`, `План-работы/`, `Этап-уже-сделанного/`.

## Как развернуть проект вручную (без ИИ)

1. Откройте 1С:Предприятие.
2. Добавьте существующую информационную базу, указав путь к папке `InfoBase` из этого репозитория.
3. Запустите в режиме "Конфигуратор".
4. Если база пустая, загрузите дамп: `Администрирование` -> `Загрузить информационную базу...` -> выберите файл `КурсоваяИТОГ.dt`.
5. Запустите базу в режиме 1С:Предприятие (F5) и приступайте к работе.
