# Краткие требования и задания из методического пособия

Данный документ содержит строгую выжимку задач и требований к курсовой работе, описанных в официальном методическом пособии. Мы будем ориентироваться на этот список для успешной защиты.

## 1. Задачи курсовой работы
Согласно странице 2 методического пособия, необходимо выполнить 5 ключевых задач:
1. **Анализ требований:** Выполнить анализ требований для автоматизации заданного бизнес-процесса.
2. **Проектирование структуры:** Используя прототипы (шаблоны), спроектировать структуру прикладного решения.
3. **Написание кода (расширение):** Выполнить расширение базовой функциональности, унаследованной от прототипов, для реализации конкретных особенностей бизнес-процесса (написать алгоритмы во встроенном языке 1С).
4. **Управляемый интерфейс:** Используя декларативное описание, построить управляемый интерфейс приложения (подсистемы, формы).
5. **Командный интерфейс:** Построить командный интерфейс приложения – средство навигации пользователя в зависимости от прав (роли, аутентификация).

## 2. Обязательные технические элементы (по примеру из методички)
В конфигурации обязательно должны присутствовать и быть связаны между собой следующие объекты платформы:
- **Бизнес-процессы и Задачи:** Обязательное наличие карты маршрута бизнес-процесса и механизма задач с системой персональной/ролевой адресации (связь с регистрами сведений).
- **Справочники:** Иерархические, с реквизитами, с использованием свойства "Владелец", а также использование *предопределенных* элементов справочников.
- **Перечисления:** Использование закрытых списков статусов/типов.
- **Документы:** Не менее 2-3 взаимосвязанных документов (например, документ-основание и подчиненный документ), разработка форм документов и списков.
- **Регистры сведений:** Создание как минимум одного периодического регистра (срез последних) и регистра для системы адресации задач.
- **Регистры накопления:** Создание регистра для накопления и учета движения средств (остатки или обороты).
- **Регистр бухгалтерии и План счетов:** Разработка собственного плана счетов и регистра бухгалтерии с поддержкой корреспонденции (дебет/кредит).
- **Программный код:** Написание обработчиков событий (например, "Перед записью", "При изменении") для автоматизации процессов (авторасчеты, проверки, сообщения пользователю).
- **Система компоновки данных (СКД):** Разработка аналитических отчетов на базе СКД.
- **Роли и права доступа:** Разграничение прав между разными классами пользователей (минимум 2 роли).

## 3. Структура пояснительной записки (для Word-документа)
Отчет по курсовой работе должен строго соответствовать следующей структуре:
1. Введение.
2. Анализ требований к автоматизируемому бизнес-процессу (построение BPMN модели процесса).
3. Структура прикладного решения.
4. Расширение функциональных возможностей прототипа (описание написанного кода).
5. Управляемый интерфейс приложения.
6. Командный интерфейс приложения.
7. Анализ данных и отчеты.
8. Выводы.
9. Список использованных источников.
