Лабораторная работа №3
Тема: Организация получения и вывода данных с удалённого оборудования
Вариант 1: Умный дом

Цель работы
Целью работы является освоение схемы обмена данными между клиентским интерфейсом и сервером при моделировании удалённого оборудования, с использованием периодических HTTP-запросов и ответов в формате JSON.

Задание
По методическим указаниям необходимо реализовать эмуляторы для всех классов вещей, подготовленных в предыдущей работе, обеспечить отдельную функцию подключения на сервере и отдельный AJAX-запрос на клиенте для каждой вещи, а также вывести в интерфейсе только данные мониторинга без передачи управляющих команд на данном этапе.

Ход работы
В серверной части для каждого типа устройства реализован метод эмуляции, который обновляет внутреннее состояние объекта случайными или логически допустимыми значениями, и метод опроса, который после эмуляции формирует JSON с актуальными полями. Для температурного датчика в ответ включена числовая величина, для освещения — признак включения и уровень яркости, для замка — признак «закрыт». Маршрутизация организована так, что каждая вещь имеет собственный URL опроса, что соответствует требованию о раздельных функциях подключения.

Клиентская страница размещена в шаблоне и подключает таблицу стилей и библиотеку для выполнения асинхронных запросов. В отдельном сценарии заданы три функции опроса, каждая обращается к своему адресу, ожидает тип данных JSON и записывает результат в соответствующие элементы формы. Периодический опрос выполняется с интервалом в одну секунду, что демонстрируу непрерывное обновление мониторинга.

Вывод
В результате получено веб-приложение с эмуляцией трёх устройств и раздельными запросами мониторинга для каждой вещи. Интерфейс отображает только данные наблюдения, что соответствует границам третьей лабораторной работы и создаёт основу для передачи управляющих команд в следующей.
