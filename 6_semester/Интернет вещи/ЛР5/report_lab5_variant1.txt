Лабораторная работа №5
Тема: Создание и настройка системы управления оборудованием на базе платформы Интернета вещей (проверка и приведение данных)
Вариант 1: Умный дом

Цель работы
Целью работы является освоение приёма данных из внешних интерфейсов в заранее не гарантированном формате и их проверки на стороне сервера перед изменением состояния цифровых двойников.

Задание
По методическим указаниям необходимо модифицировать функции приёма данных от вещей так, чтобы все входящие значения проходили проверку. Требуется как минимум два различных формата входа, включая строковый, и использование хотя бы одного регулярного выражения.

Ход работы
Серверная логика команд расширена блоками проверки. Для температуры используется приведение с помощью функции вещественного типа внутри конструкции обработки исключений: при невозможности преобразования запись нового значения не выполняется, в ответе возвращается признак ошибки, в журнал записывается предупреждение. Для яркости освещения применяется целочисленное преобразование с проверкой диапазона от нуля до ста процентов, а для признака включения вводится строковый шаблон, допускающий несколько удобочитаемых вариантов записи, отобранных регулярным выражением. Для замка реализован отдельный строковый формат с жёстким допуском только двух лексем, задающих состояние запирания; соответствие строки шаблону проверяется регулярным выражением с полным совпадением всей строки.

Клиентская страница скорректирована под новые правила: для замка вводится текстовое поле с ожидаемыми словами, для света допускаются текстовые обозначения включения наряду с цифровой яркостью, для температуры сохраняется числовой ввод с возможностью десятичной запятой. Ответы об ошибках отображаются пользователю через диалог, что упрощает демонстрацию отказа в обработке некорректных данных.

Вывод
В результате входящие параметры команд проходят типовую и содержательную проверку до изменения состояния устройств. Сочетание контроля исключений при числовом разборе и регулярных выражений для строк соответствует требованиям пятой лабораторной работы и снижает риск некорректного управления моделью умного дома.
