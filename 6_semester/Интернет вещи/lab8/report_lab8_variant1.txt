Лабораторная работа №8
Тема: Разработка модуля анализа данных в системах интернета вещей
Вариант 1: Умный дом

Цель работы
Целью лабораторной работы является получение практических навыков анализа данных, накопленных в базе данных системы «умный дом», и представления результатов анализа через API и веб-интерфейс.

Задание
В соответствии с методическими указаниями для лабораторной работы №8 требуется реализовать модуль, вычисляющий не менее двух характеристик по накопленным данным. В работе рассчитаны среднее и максимальное значения температуры, а также количество состояний обогревателя в режимах On и Off.

Ход работы
В ходе выполнения лабораторной работы сохранены функции мониторинга, управления и логирования данных в MongoDB, реализованные в предыдущих работах, и добавлен модуль анализа данных. На сервере реализован маршрут `GET /analysis/stats`, формирующий сводный JSON-ответ по содержимому коллекций `Temperature` и `Heater`. На рисунке 1 изображена страница ЛР8 с блоком «Анализ данных» и кнопкой запроса статистики.

Для температурных данных выполняется выборка из коллекции `Temperature`, после чего рассчитываются среднее арифметическое значение, максимальное значение и количество записей. Для второй характеристики выполняется подсчёт количества документов в коллекции `Heater` по состояниям `On` и `Off`. Вывод
В результате выполнения лабораторной работы реализован модуль анализа данных поверх накопленного журнала MongoDB без изменения существующего формата записи телеметрии. Полученная реализация обеспечивает вычисление нескольких характеристик и их выдачу через API и веб-интерфейс, что соответствует требованиям лабораторной работы №8.
