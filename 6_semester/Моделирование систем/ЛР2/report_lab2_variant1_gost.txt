ЛАБОРАТОРНАЯ РАБОТА 2
Моделирование дискретной случайной величины
Вариант 1

Цель
Целью лабораторной работы является программная реализация датчика дискретной случайной величины по заданному закону распределения и проверка соответствия эмпирических характеристик теоретическим значениям.

Задание и исходные данные
В работе необходимо реализовать датчик дискретной случайной величины x, которая принимает конечное множество значений с заданными вероятностями. Номер варианта 1 определяет набор значений xj и вероятностей pj из таблицы методических указаний. На основе этих данных требуется сформировать накопленные вероятности и использовать их для генерации выборки. Таблица исходных данных варианта вставляется в отчет отдельным рисунком или таблицей.

Ход выполнения задания
Для моделирования дискретной случайной величины использован стандартный подход с разбиением интервала от 0 до 1 на участки, длины которых равны вероятностям pj. Далее для каждого сгенерированного значения базовой случайной величины выбирается тот интервал, в который оно попадает, и этому интервалу ставится в соответствие конкретное значение xj. Такой алгоритм реализован в файле программы lab2_modeling.py и обеспечивает прямое соответствие заданному распределению варианта.

После реализации датчика была получена выборка объема N равного 500, как требуется в методических указаниях. Для воспроизводимости результатов использовано фиксированное начальное состояние генератора случайных чисел. По полученной выборке вычислены эмпирические оценки математического ожидания и дисперсии, а затем выполнено сравнение с теоретическими значениями, рассчитанными по формулам методички.

На заключительном этапе выполнен анализ распределения вероятностей по значениям xj. Были построены графики для эмпирических и теоретических вероятностей, а также их визуальное сопоставление. Графики сохранены в папке plots и используются как иллюстрации в отчете. По результатам сравнения сделана итоговая оценка качества моделирования дискретной случайной величины.

3.1 Программная реализация датчика и генерация выборки
Алгоритм генерации построен на сопоставлении отрезков интервала от 0 до 1 с вероятностями заданных значений случайной величины. Сначала для всех вероятностей формируются накопленные границы, которые делят интервал на последовательные участки. Далее для каждого шага моделирования генерируется случайное число на интервале от 0 до 1, определяется номер участка, куда это число попало, и в выборку записывается соответствующее значение xj. Таким образом реализуется прямое воспроизведение дискретного закона распределения.

После генерации всей последовательности из 500 значений выполняется обработка результатов. По выборке определяются частоты появления каждого значения, затем рассчитываются эмпирические оценки математического ожидания и дисперсии, и проводится сравнение с теоретическими характеристиками. На основе этих же частот строятся гистограммы, по которым визуально оценивается, насколько полученное эмпирическое распределение совпадает с заданным теоретическим.
