Отчёт о лабораторной работе № 6

1. Цель работы

Получение навыков создания и использования хранимых процедур и функций в PostgreSQL: вставка и удаление данных с обновлением связанных справочников, агрегатные и табличные функции, использование временных таблиц и управляющих конструкций в процедурном коде.

2. Задание

Вариант 5.

На базе данных варианта 5 реализовать хранимые процедуры и функции по п. 6.4: вставка студента с при необходимости созданием строки в справочнике «Группа»; удаление студента с удалением пустой группы; каскадное удаление группы со студентами и участиями в выступлениях; скалярную агрегатную функцию; заполнение временной таблицы статистикой по факультетам. Дополнительно — демонстрация цикла по данным и табличной функции (пп. 6.1 и 6.3).

3. Ход работы

После подключения к базе данных варианта 5 в PostgreSQL выполнялся скрипт с определениями объектов и примерами вызовов.

Создана процедура добавления студента по ФИО, номеру группы и номеру факультета вуза «ГУАП»: при отсутствии группы с данной парой (факультет, номер группы) в таблицу «Группа» добавляется новая строка, затем вставляется студент; при попытке повторно вставить того же студента в ту же группу выводится предупреждение и вставка не выполняется.

Создана процедура удаления студента по ФИО: удаляются строки участия в «Выступление_студент», затем студент; если в группе не осталось студентов, удаляется строка «Группа».

Создана процедура каскадного удаления группы по номеру группы, номеру факультета и вузу: сначала удаляются участия студентов этой группы, затем студенты, затем группа.

Реализована скалярная функция среднего числа участий в выступлениях на одного студента по выбранному вузу; в среднее входят все студенты вуза, в том числе без выступлений (ноль участий).

Реализована процедура заполнения временной таблицы tmp_faculty_stats: по каждому факультету вуза «ГУАП» подсчитываются число групп, число студентов, число участий в выступлениях и средняя длина названия темы выступлений студентов факультета.

Для иллюстрации управляющих конструкций добавлена процедура с циклом по конференциям и заполнением временной таблицы tmp_conf_loop числом участий в выступлениях по каждой конференции для вуза.

Реализована табличная функция, возвращающая список студентов (ФИО и номер группы), имевших участие в выступлениях программы указанной конференции.

Добавлен отдельный сценарий с использованием CASE: по каждому студенту формируется категория активности в зависимости от числа участий в выступлениях (нет участий, низкая, средняя, высокая), результат сохраняется во временной таблице.

4. Вывод

В ходе работы на базе варианта 5 созданы хранимые процедуры для вставки студента с пополнением справочника «Группа», для удаления студента с очисткой пустой группы и для каскадного удаления группы, реализованы скалярная агрегатная и табличная функции, процедуры с временными таблицами и циклом по конференциям, а также сценарий классификации активности студентов через CASE; получен практический опыт использования объектов PL/pgSQL в PostgreSQL.
