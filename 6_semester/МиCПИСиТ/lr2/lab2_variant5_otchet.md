# Отчёт о лабораторной работе № 2

## 1. Цель работы

Освоить заполнение таблиц тестовыми данными, исправление и удаление строк операторами update и delete, а также точечное изменение структуры таблиц оператором alter table в среде PostgreSQL на базе схемы, созданной в первой лабораторной работе.

## 2. Задание

Вариант 5. По пособию необходимо вставить тестовые данные в таблицы лабораторной работы 1; в наборе должны быть строки, подходящие и не подходящие под условия будущих запросов приложения к варианту. Ошибочные данные исправлять update и delete. При необходимости корректировать структуру БД через alter table. Исходная схема задаётся скриптом lr1/lab1_variant5_postgresql.sql с целочисленными ключами integer и generated by default as identity. Данные и примеры DML оформлены в файле lr2/lab2_variant5_data.sql; отдельный перенос с uuid на integer не выполняется, файл lr2/lab2_variant5_alter_uuid_to_integer.sql в актуальной цепочке не используется.

## 3. Результат проделанной работы

После выполнения скрипта первой лабораторной работы запускался скрипт lab2_variant5_data.sql. В нём использованы операторы insert в форме insert into имя_таблицы список_столбцов values с явными целыми значениями первичных ключей и конструкция overriding system value для столбцов identity, что соответствует приёму из методички для таблиц с автонумерацией. Для связующей таблицы Выступление_студент указаны только внешние ключи, составной первичный ключ образуется парой столбцов без identity.

Показана вставка по выборке insert into Выступление_студент select с соединением Выступление и Студент по условиям на фамилию и название темы. Продемонстрированы update названия темы выступления и двухшаговое исправление ФИО студента, удаление строки участия и удаление выступления с идентификатором девять. Для иллюстрации alter table к таблице Студент добавлялся столбец Email varchar, выполнялось заполнение для студентов группы с номером 4226 через update с from по таблице Группа, затем столбец удалялся, так что итоговая схема совпадает с результатом первой лабораторной работы.

В закомментированном виде приведены примеры некорректных вставок несуществующая группа, нарушение check по номеру факультета, пустое ФИО из пробелов, а также удаление факультета с номером четыре для демонстрации каскадного удаления по ранее заданным внешним ключам. В конце скрипта вызывается setval для последовательностей, связанных со столбцами identity, по текущему максимуму идентификаторов, чтобы последующие автоматические вставки не дублировали ключи.

По содержанию тестовых строк отражены один вуз ГУАП, четыре факультета с номерами один–четыре, шесть групп, восемь студентов, три конференции с программами и набором выступлений, в том числе совместное выступление студентов с разных факультетов и участие одной студентки во всех трёх конференциях; студенты четвёртого факультета не включены в выступления для проверки условий вида не выступавших.

## 4. Вывод

База vuz_lr1 для варианта 5 наполнена согласованными тестовыми данными с явными целочисленными ключами в стиле пособия, отработаны insert update delete и alter table, показаны отказы при нарушении ограничений и назначение каскадных правил на внешних ключах из первой работы.
